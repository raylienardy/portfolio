# LIENARDY — Portfolio

Static personal portfolio website for LIENARDY — Full-Stack Web & Mobile Developer.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Typed.js
- Font Awesome (Kit)
- Google Fonts (Poppins, Clicker Script)

## Features

- Responsive design
- Smooth navigation (custom RAF)
- Scroll spy
- Dark/light mode
- Theme color switcher
- Portfolio showcase
- Contact links

## Local Preview

```bash
python -m http.server 8000
```

Open http://localhost:8000

## Hosting

Designed for static hosting such as GitHub Pages. All asset paths are relative.
